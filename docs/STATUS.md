# Status

DeckWright is a local Commander deckbuilding assistant. It runs on your machine via `./run.sh` and is not offered as a hosted service.

## What works today

- Interrogation → real commanders → Scryfall-grounded 99
- Solitaire goldfish thesis and plan diagnostics
- Saved decks under `~/.deckwright/`, export, precon browse (Archidekt at runtime)
- Offline merge gate: `python scripts/check_all.py --tier 1`

See the root [README](../README.md) for quick start, and [HOW-IT-CONNECTS.md](HOW-IT-CONNECTS.md) for how the pieces join.
